# async-only / 공통 TPS 검증

2026-09-14에 다음 검증을 완료했다.

- 독립 적대적 리뷰 2인 승인. 각 리뷰어가 오프라인 테스트 113개와 하위 테스트
  14개를 통과했고, 공급자 주입·공유 과금·취소·세션 종료·오류 마스킹을 검증했다.
- 전체 오프라인 테스트 113개, 하위 테스트 14개 통과. 커버리지 91.54%.
  ruff, mypy, compileall, SKILL 검증 및 CodeGraph 갱신 통과.
- 리뷰 후 live E2E: KAC 김포공항 주차요금과 IIAC 주차현황의 실제 데이터 검증 성공.
- KAC 김포공항 출발편 조회는 HTTP 200 응답 안에
  `SERVICE ACCESS DENIED ERROR.`를 반환했다. 해당 테스트는 skip이며 성공에
  포함하지 않는다. 별도 공개 클라이언트 호출로 HTTP 상태와 오류를 재확인했다.
- HTTP 403은 관측되지 않았다. 출발편 데이터 검증 제한을 사용자에게 보고했고,
  403 없는 저장소를 머지하라는 사용자 지시에 따라 머지를 진행한다.

동기 클라이언트와 Async 접두사 별칭은 제거했다. 모든 네트워크 호출·디버그·
페이지 순회는 native async이며 KAC와 IIAC가 같은 AsyncTokenBucket을 공유한다.
재시도와 HTTPX 리다이렉트마다 토큰을 사용한다. 주입한 HTTP 세션의 수명은
호출자가 관리하며 내부 생성 세션은 async 문맥 종료 시 닫힌다.
